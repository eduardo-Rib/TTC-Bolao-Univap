# ⚽ Sistema de Gestão de Bolão de Futebol

Projeto desenvolvido como **Trabalho de Conclusão de Curso (TCC)** em 2023.

O sistema foi criado para **automatizar a gestão de um bolão de futebol** organizado entre os professores do curso técnico da minha instituição. Antes do sistema, todo o processo era feito manualmente, desde o registro de palpites até a conferência de resultados.

Este projeto foi desenvolvido utilizando **C#, .NET 7.0, Windows Forms e SQL**.

> ⚠️ Observação: O projeto está sendo publicado no GitHub posteriormente, pois na época do desenvolvimento (2023) eu ainda não utilizava GitHub para versionamento.

---

# 📌 Funcionalidades

- Cadastro de participantes do bolão
- Registro de palpites para cada rodada
- Armazenamento dos jogos e resultados
- Cálculo da pontuação dos participantes
- Visualização do ranking do bolão
- Persistência de dados em banco SQL

O objetivo principal é **facilitar a administração do bolão**, reduzindo erros humanos e o tempo gasto na organização.

# 🗂️ Estrutura geral do sistema

O sistema é composto por:

- Interface gráfica em **Windows Forms**
- Camada de acesso ao **banco de dados SQL**
- Lógica de cálculo de pontuação e gerenciamento dos palpites

Fluxo básico:

1. Cadastro dos participantes
2. Cadastro das rodadas e jogos
3. Inserção dos palpites
4. Inserção dos resultados reais
5. Cálculo automático da pontuação
6. Atualização do ranking do bolão
